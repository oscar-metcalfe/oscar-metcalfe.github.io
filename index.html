Connect your Google account

This page talks directly to the real Google Tasks API from your browser — there's no server in between, so it works the same on desktop and mobile. Google requires a one-time free setup so the page can ask for permission:

  1. Go to console.cloud.google.com/apis/credentials (free Google account is enough, no billing needed).
  2. Create a project if you don't have one, then click Create Credentials → OAuth client ID.
  3. Application type: Web application.
  4. Under Authorized JavaScript origins, add exactly: https://oscar-metcalfe.github.io
  5. You'll also need to enable the Google Tasks API for that project, and add your own Google account as a test user on the OAuth consent screen (since this is just for you, it doesn't need Google's review).
  6. Copy the generated Client ID and paste it below.

Sign in to Google Tasks

Your tasks, projects, and subtasks will be read from and written to your real Google Tasks account. Nothing is stored on this page or on any server.
